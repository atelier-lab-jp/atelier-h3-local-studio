# ATELIER H3 Local Studio

**Mac の中だけで動く、音声つき動画の生成スタジオです。**
インターネット上のサービスには一切つながりません（外部API・クラウド・ログインなし）。
生成した動画も記録も、すべてこの Mac の中だけに残ります。

- 作れるもの: 576×320・24fps の音声つき動画（**約2.33秒** または **約5.17秒**）
- 長い動画は「続きを作る」→「つなげる」で作ります（後述）
- iPhone・iPad からも操作できます（**同じWi-Fiの中だけ**。後述）

> **これはネイティブアプリ（App Store のアプリ）ではありません。**
> Mac の中で小さなサーバーを動かし、それを Safari などのブラウザから操作する
> **ローカルWebアプリ**です。ですからアプリを終了すると画面も使えなくなります。

## 1. 必要なもの

| 項目 | 内容 |
|---|---|
| パソコン | Apple シリコンの Mac（macOS）。動作確認は Mac mini M4・メモリ24GB |
| 生成の中身 | DiffSynth-Studio と MiniMax-H3 のモデル一式（別途セットアップ済みであること） |
| ブラウザ | Safari / Chrome など |
| インターネット | **不要**（初回の準備でだけ使います） |

「画面の動きだけ試したい」場合は、モデルが無くても**お試しモード**で動かせます（[11章](#11-開発者向け)）。

## 2. 最初の準備（初回だけ）

1. Finder で `atelier-h3-local-studio` フォルダを開きます。
2. `scripts` フォルダの中の **`setup.sh`** を使います。ターミナルに慣れていない場合は、
   「アプリケーション → ユーティリティ → ターミナル」を開き、次の2行をコピーして貼り付け、
   最後に `return`（Enter）キーを押してください。

```
cd ~/dev/atelier-h3-local-studio   # 実際に置いた場所に読み替えてください
./scripts/setup.sh
```

3. 文字がたくさん流れます。最後に「完了」と出れば成功です（数分かかることがあります）。

準備でやっていること:

- このアプリ専用の Python 環境（`.venv`）を作ります
- **すでにある DiffSynth-Studio・モデル・その環境には一切触れません**
- お試しモード用の短いダミー動画を作ります

## 3. 起動と終了

### 起動する（かんたんな方法）

Finder で `scripts` フォルダを開き、**`ATELIER H3 Studio.command` をダブルクリック**します。
黒い画面（ターミナル）が開いて、しばらくするとブラウザで
`http://127.0.0.1:7860` が自動的に開きます。

#### 初回だけ出る警告への対処（Gatekeeper）

はじめてダブルクリックしたときに

> 「開発元が未確認のため開けません」「悪質なソフトウェアかどうかを確認できません」

と出ることがあります。これは macOS の安全機能（Gatekeeper）です。次のようにします。

1. `ATELIER H3 Studio.command` を **右クリック**（または control キーを押しながらクリック）
2. メニューの **［開く］** を選ぶ
3. 確認のダイアログでもう一度 **［開く］** を押す

**2回目からはダブルクリックで開けます。**
（システム設定 → プライバシーとセキュリティ に「このまま開く」ボタンが出ている場合も、そちらから許可できます）

### 起動する（ターミナルを使う方法）

```
cd ~/dev/atelier-h3-local-studio   # 実際に置いた場所に読み替えてください
./scripts/start.sh
```

### 終了する

**ターミナル（黒い画面）をクリックして `Control` キーと `C` キーを同時に押します。**
「終了します…」と出て停止します。ブラウザのタブを閉じただけでは終了しません。

> ⚠️ 生成中に終了すると、その動画はできあがりません（記録には「中断」と残ります）。
> できれば生成が終わってから終了してください。

### 注意

- 待ち受けは `127.0.0.1`（この Mac の中だけ）です。ふつうの起動では外からは見えません。
- 生成は**必ず1本ずつ**です。2本頼むと順番待ちになります。
- **同時に2つ起動しないでください**（メモリが足りなくなります）。
- 生成中は Mac がスリープしないようにしてください（`.command` から起動した場合は自動でスリープを防ぎます）。

## 4. 画面の使い方

画面は4つのタブに分かれています。

### ① 新規生成

1. **プロンプト**（どんな動画にするか）を **英語** で書きます。
   日本語のセリフは `<d>[Japanese] ここにセリフ</d>` のように囲みます。
   ［＋日本語セリフ記法を挿入］ボタンで雛形を入れられます。
   書き直したいときは ［プロンプトを消去］ で入力欄だけを空にできます
   （長さ・品質・シードの設定と、すでに登録した生成はそのまま残ります）。
2. **動画の長さ** を選びます（約2.33秒 / 約5.17秒）。
3. **品質** を選びます（4ステップ＝高速 / 8ステップ＝高品質・時間は約1.7倍）。
4. **シード** は「ランダム」のままで大丈夫です。同じ絵柄をもう一度出したいときだけ数値を指定します。
5. **［▶ 生成をキューに追加］** を押します。

押した直後にボタンが一時的に押せなくなり、画面がすぐ戻ります。
**続けて2回押しても、生成は1本しか登録されません**（同じ内容をわざと2本作りたいときは、数秒おいてからもう一度押してください）。

生成の進み具合は同じ画面の「現在の処理」に出ます。できあがると右側で再生できます。

### ② キュー

いま何をしているか、あと何本待っているかを見る画面です。

- **現在の処理** — ステップ（1/4〜4/4）・経過時間・目安時間
  - ⚠️ **ステップが 4/4 になってからも数分かかります**（映像と音声に変換しています）。
    「最終処理中」と表示され、経過時間は進み続けます。**故障ではありません。**
- **待機中のジョブ** — 順番待ちの一覧。まだ始まっていないものは取り消せます
  （実行中のものは取り消せません）
- **生成エンジンの状態** — 待機中／生成中／再起動待ち など
- **［⚠ ワーカーを再起動する］** — どうしても進まなくなったときの最後の手段です。
  **実行中の1本は失敗になります**（待機中のものは残ります）
- **詳しい情報** — うまくいかないときに開く、技術的な記録です。ふだんは開かなくて大丈夫です

### ③ 完成・編集

できあがった動画を**選んで・見て・つなげる**ための作業画面です
（続きを作る／つなげる／Finderで表示）。

タブのいちばん上に **［表示する動画を選ぶ（個別／連結）］** があります。
見たい動画を選んで ［↻ 選んだ動画を表示］ を押すと、右側（iPhone では下）に
再生画面と詳しい内容が出ます。

その下に **完成した動画が何件あるか**（個別・連結の内訳）が出ます。
**動画の一覧表は「履歴」タブ**にまとめてあるので、この画面は短いまま保たれ、
下の「順番指定連結」まですぐ届きます。

#### いらない動画を片づける

動画を選ぶと、右側（iPhone では下）に **［この動画を整理する］** が出ます。
確認のチェックを入れてから赤い **［🗑 ゴミ箱へ移動］** を押すと、その動画を
`data/trash/` へ移します。

- **アプリ上の復元機能はありません。** 戻したいときは Finder で `data/trash/` から
  元のフォルダ（`data/outputs/` または `data/concat/`）へ動かしてください。
  戻せば画面にもまた出てきます
- 移動するのは**選んだ動画だけ**です。その動画を使って作った**連結動画は消えません**
- 生成や連結の最中は整理できません（終わってからにしてください）

Finder で直接消した動画は、次の画面更新で自動的に一覧から消えます
（「見つかりません」という記録が残り続けることはありません）。

#### 好きな順番でつなげる

画面の下半分にある **［複数の動画を選んで連結（順番指定）］** で、好きな動画を
好きな順番で1本にまとめられます。

1. ［追加する動画を選ぶ］で動画を選び、**［＋ 連結候補へ追加］** を押す
2. 選んだ動画が **1、2、3…** の番号付きで並びます（この**上から順**につながります）
3. 順番を変えたいときは ［対象を選ぶ］で動画を選び、**［↑ 1つ上へ］［↓ 1つ下へ］** を押す
4. いらない動画は ［対象を選ぶ］で選んで **［－ 候補から外す］**、
   やり直すときは ［連結候補をすべて解除］
   （どちらも**この画面で組み立てている順番から外すだけ**で、動画は削除されません）
5. 2本以上そろったら **［▶ この順番で連結］** を押す

できあがった動画は ［表示する動画を選ぶ］ に「連結」として並び、これまでの連結動画と
同じように再生・Finder表示ができます。**元の動画は変わりません**（新しい動画が1本
増えるだけです）。つないだ動画の一覧は「履歴」タブの **［連結成果物］** で見られます。

- 2〜20本まで選べます。同じ動画を2回入れることはできません
- つなげられるのは**個別動画だけ**です（つなげた動画をさらに素材にはできません）
- 連結は一度に1つずつです。実行中に別の連結を始めようとすると、その旨が表示されます

### ④ 履歴

これまでの全記録（成功・失敗・取消・中断）を表で見られます。
**iPhone では表が横に長いので、表の中を横になぞる**と残りの列が見られます。

上の **状態フィルタ** で表示を絞り込めます。いちばん右の **［連結成果物］** を選ぶと、
つないだ動画（チェーン連結・指定順連結）だけを、**元の動画と順番つき**で確認できます。

## 5. 長い動画を作る（続きを作る・つなげる）

1本の動画は最大でも約5.17秒です。長い動画は「続きを作って、あとでつなげる」方法で作ります。

1. 「完成・編集」タブで、もとにする動画を選ぶ
2. **［この動画の続きを作る］** を押す
3. 「新規生成」タブに切り替わります。**前の動画の最後のコマ**が続きの最初のコマになります
   （シード・長さ・ステップ・プロンプトも引き継がれます）
4. **キャラクターと声の説明はそのままにして、セリフと動きだけ**書き換えて生成します
5. できあがったら「完成・編集」タブで**いちばん新しい動画**を選び、
   **［ルートからここまでを連結］** を押します
6. 最初の動画から選んだ動画までが、音声つきの1本につながります（もとの動画も残ります）

覚えておくこと:

- 引き継ぎは **「よく似た雰囲気になる」** という程度です。まったく同じにはなりません
- つなげられるのは最大20本までです
- つなぎ目では同じような絵が一瞬長く見えることがあります（仕様です）
- できた動画は `data/concat/` に入ります

## 6. iPhone・iPad から使う（LANモード）

**同じWi-Fi（同じルーター）につながっている iPhone から、この Mac のアプリを操作できます。**
生成そのものは Mac が行い、iPhone は「操作するための画面」になります。

### 起動のしかた

Finder の `scripts` フォルダで
**`ATELIER H3 Studio LAN.command` をダブルクリック**します
（初回だけ、[3章の Gatekeeper 対処](#初回だけ出る警告への対処gatekeeper)と同じ「右クリック→開く」が必要です）。

ターミナルを使う場合は次のとおりです。

```
cd ~/dev/atelier-h3-local-studio   # 実際に置いた場所に読み替えてください
./scripts/start.sh --lan
```

### 起動すると Mac の画面に出るもの

- **iPhone で開くアドレス**（例: `http://192.168.1.23:7860`）
- **QRコード**（iPhone のカメラで読み取ると、そのアドレスを開けます）
- **ユーザー名**（`h3` で固定）と **パスワード（数字のPIN）**

> 🔑 **PIN は Mac の画面にしか出ません。**（起動のたびに変わります）
> iPhone 側の画面にも、QRコードの中にも、記録ファイルにも入りません。

### iPhone での操作

1. iPhone を **Mac と同じWi-Fi** につなぐ
2. カメラで QRコードを読み取る（またはアドレスを Safari に手で入力する）
3. ログイン画面が出たら、**ユーザー名に `h3`**、**パスワードに Mac の画面の数字**を入力する
4. いつもの画面が出れば成功です

Mac に「**ネットワーク上の接続を許可しますか**」というダイアログが出たら **［許可］** を押してください
（macOS のファイアウォールの確認です）。

### ホーム画面に追加すると使いやすくなります

Safari で開いた状態で、画面下の **［共有］**（□に↑のマーク）→ **［ホーム画面に追加］** を選ぶと、
アプリのように1タップで開けるようになります。
**ただし中身は Safari で開く Web ページで、ネイティブアプリではありません。**
Mac 側のアプリを終了していると開けません。

### ⚠️ 安全のための注意（必ず読んでください）

- これは **同じWi-Fiの中だけで使う簡易的な認証**です。数字のPINだけで守っています
- 通信は **HTTPS ではありません（暗号化されていません）**。
  **カフェ・空港・ホテル・学校・会社など、知らない人がいるネットワークでは使わないでください。**
  自宅など、信頼できるWi-Fiでだけお使いください
- インターネットには公開していません（外部トンネルは使いません）
- 使い終わったら Mac の画面で **Control+C** を押して終了してください
- **ゲスト用Wi-Fi**や「端末どうしの通信を禁止」する設定のWi-Fiでは、
  iPhone から Mac に届かないため使えません

### iPhone ではできないこと

- **［Finderで表示（Macのみ）］** は Mac 側の Finder を開く機能です。
  iPhone から押すと **Mac の画面** でフォルダが開きます（iPhone には何も出ません）
- iPhone に動画を保存したいときは、**プレビューを長押し → 「ビデオを保存」** を使ってください

### 画面を閉じても大丈夫です

生成は Mac の中で進みます。**Safari を閉じても、iPhone がスリープしても、生成は止まりません。**
あとでもう一度開けば、そのときの状態（順番待ち・進み具合）がそのまま出ます。

## 7. できあがったファイルの場所

| 内容 | 場所 |
|---|---|
| 生成した動画 | `data/outputs/` |
| つなげた動画 | `data/concat/` |
| ゴミ箱へ移した動画 | `data/trash/` |
| 記録（履歴） | `data/history.json` |
| 動作の記録（ログ） | `data/logs/` |

- アプリからは **［🗑 ゴミ箱へ移動］** で `data/trash/` へ移せます（完全には消しません）。
  そこから先の削除・復元は **Finder から自分で**行ってください
- 空き容量が **20GB** を切ると警告、**5GB** を切ると新しい生成を受け付けなくなります
  （そのときは Finder で不要な動画を減らしてください）

## 8. 目安の時間

Mac mini M4（メモリ24GB）での実測です。

| 長さ | 品質 | 目安 |
|---|---|---|
| 約2.33秒（56フレーム） | 4ステップ | **約6〜7分**（実測 403秒） |
| 約5.17秒（124フレーム） | 4ステップ | **約13〜14分**（実測 819秒） |
| 約2.33秒（56フレーム） | 8ステップ | **約11〜12分**（実測 678秒） |
| 約5.17秒（124フレーム） | 8ステップ | **約22〜23分**（※この組み合わせだけ**推定**） |

- 8ステップは 4ステップの **約1.7倍**の時間がかかります（実測 1.67倍）
- ステップが 4/4（8/8）になってからも、映像と音声への変換に **2〜3分**かかります

## 9. 困ったときは

| 症状 | 対処 |
|---|---|
| ダブルクリックで「開発元が未確認」と出る | 右クリック → ［開く］ → もう一度［開く］（[3章](#初回だけ出る警告への対処gatekeeper)） |
| ブラウザが自動で開かない | ブラウザで `http://127.0.0.1:7860` を手で開く |
| 4/4 になったのに終わらない | **正常です。**2〜3分お待ちください（「最終処理中」と出ます） |
| ずっと進まない | 「キュー」タブの ［⚠ ワーカーを再起動する］（実行中の1本は失敗になります） |
| 赤い帯が出た | 書いてある内容に従ってください（空き容量不足／エンジン停止） |
| iPhone からつながらない | ①同じWi-Fiか ②ゲストWi-Fiではないか ③Mac のファイアウォールで［許可］したか ④Mac のアプリが動いているか |
| PIN を忘れた | Mac の画面（ターミナル）に出ています。見当たらなければ Control+C で終了し、起動し直してください（PINは毎回変わります） |
| 何が起きたか詳しく知りたい | 各タブの **「詳しい情報」** を開くと、技術的な記録が見られます |
| 動画が再生できない | ファイルを移動・削除していないか確認してください（「ファイルが見つかりません」と出ます） |

エラー画面には必ず **エラーの種類** と **ジョブID**（`v_2026...` のような文字列）が出ます。
だれかに相談するときは、この2つと「詳しい情報」の内容をそのまま伝えてください。

## 10. してはいけないこと

- **同時に2つ起動しない**（メモリ不足になります）
- **生成中に Mac をスリープさせない**
- `data/` の中のファイルを、生成中に移動・削除しない
- 知らない人がいるWi-FiでLANモードを使わない（[6章](#️-安全のための注意必ず読んでください)）
- 解像度・fps・長さ・ステップの選択肢を勝手に増やさない（実機で検証済みの組み合わせだけを使っています）

## 11. 開発者向け

### 実機モードとお試し（モック）モード

| モード | 起動方法 | 生成時間 | 用途 |
|---|---|---|---|
| **実機（既定）** | `./scripts/start.sh` | 1本 約6〜7分 | 本番。実際の AI モデルで生成 |
| お試し（モック） | `./scripts/start.sh --mode mock` | 数秒 | 画面の動作確認。ダミー動画が出ます |

### 起動前チェックだけ実行する

```
./scripts/start.sh --check                          # 現在のモードでチェック
./scripts/start.sh --check --mode real              # 実機の資産（モデル・LoRA）を検査
./scripts/start.sh --check --mode real --deep-check # 既存Python環境のパッケージも検査
```

### テスト

```
.venv/bin/python -m pytest tests/ -v
```

**実モデルは使いません**（数分かかる実機生成はテストに含めない方針です）。
